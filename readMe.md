Welcome to Recipe Mate!
Recipe Mate helps users to manage their calorie intake by keeping a list of recipes and calculating macros.
The aim of this project is to allow a user to:

1. View recipes
2. Convert recipes
3. Change serving sizes
4. Calculate macros
5. Set macro goals
6. Compare macros to goals
7. Find recipes
8. Add recipes
9. Exit
